# Listen Osho for Android

Downloads of the [Listen Osho](https://listenosho.com) Android app. **Android only**: the app does not install on iPhone, iPad or a computer.

Get it from [listenosho.com](https://listenosho.com) (the "Download APK" button), or from the [latest release](https://github.com/Manish-Sharma09/listen-osho-android/releases/latest). Open the downloaded file on your phone, and allow installs from your browser if Android asks.

This repository only holds the app's releases. listenosho.com serves the newest one at https://listenosho.com/download/listen-osho.apk.
